Standard holds state-changing methods. Strict permits the first document bootstrap and then holds all upstream requests. Custom applies host/path/method rules and defaults unmatched requests to Standard. Rust enforces each policy independently for every session.

The browser talks HTTP to this loopback app; Rust makes verified HTTPS connections upstream. Each session has a distinct session-id.localhost origin, separate from the dashboard and authority API. This is not transparent interception of arbitrary HTTPS tabs and requires no browser CA.

Only visit sites you trust. Per-session origins reduce access to the dashboard and other sessions, but this is not a universal JavaScript sandbox. WebSockets, WebTransport, HTTP/3, and full service-worker lifecycle compatibility are not implemented.
