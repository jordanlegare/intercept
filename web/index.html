INTERCEPT_

Open one HTTP or HTTPS origin through the local relay. The website is served through localhost with its HTTP/HTTPS resources routed and cached by Rust, while only a bottom Intercept authority banner is added to the page UI. Rust holds state-changing HTTP requests until the timer authorizes them.

The browser talks HTTP to this loopback app; Rust makes verified HTTPS connections upstream. This is a same-origin reverse-proxy session, not transparent interception of arbitrary HTTPS tabs. No browser CA installation is needed for this local-HTTP workflow.

Only visit sites you trust. A proxied site runs JavaScript in the local proxy origin. Cross-origin application requests, WebSockets, HTTP/3, and service-worker behavior are not fully proxied.
